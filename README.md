# sokoban

A classic game Sokoban, written in Python3.14

This project is rewrite. You can check the older commit how shitty the code was. I have learned a lot since then.

## Features

- Cross-platform (Windows, Linux, MacOS) [Tho' I haven't tested on Windows and MacOS yet]
- Terminal-based, no GUI required
- Random level generation
- Undo and Restart functionality
- Shows the player direction and the number of moves made [Why not? It's a feature]

## Controls

- `W` - Move Up
- `A` - Move Left
- `S` - Move Down
- `D` - Move Right
- `R` - Restart the level
- `U` - Undo the last move
- `Q` - Quit the game

You don't have to press `Enter` after pressing a key. Just press the key and the game will respond immediately. Yea, it's pretty cool.

## Installation

You just need to have Python 3.14 installed on your system. Then, you can run the game using the following command:

```bash
python3 sokoman.py
```
